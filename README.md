## 🛠️ Prerequisites

To compile and run these programs locally, ensure you have a C compiler installed:
* **GCC** (Linux / macOS / Windows via MinGW)
* **Clang** or any standard ANSI C99/C11 compiler

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/prageeshjaiin/C-Console-Applications.git](https://github.com/prageeshjaiin/C-Console-Applications.git)
   cd C-Console-Applications
   ```

2. **Compile any `.c` source file:**
   ```bash
   gcc HDFCBankingSystem.c -o HDFCBankingSystem
   ```

3. **Run the executable:**
   * **Linux / macOS:**
     ```bash
     ./HDFCBankingSystem
     ```
   * **Windows (Command Prompt / PowerShell):**
     ```cmd
     HDFCBankingSystem.exe
     ```

## 💡 Core Concepts Demonstrated

* **Procedural Architecture:** Decomposing complex workflows into reusable, single-responsibility C functions.
* **Control Flow & Menu Loops:** Managing multi-level user navigation with `switch-case`, `while`, and `do-while` loops.
* **Input Validation & Formatting:** Handling user inputs and rendering clean tabular outputs in the terminal.
