# 🖥️ C Console Applications Collection

A collection of terminal-based banking, reservation, management, and utility systems developed in **C**. These console applications demonstrate procedural programming, modular function design, control flow, and menu-driven state logic.

---

## 📂 Repository Contents

* **`hdfc_banking_system.c`** — Menu-driven banking system supporting user authentication, balance inquiry, deposits, and withdrawals.
* **`paytm_banking_system.c`** — Digital wallet workflow simulation for account transfers and transaction tracking.
* **`credit_card_management.c`** — Credit card management utility covering credit limits, billing cycles, and cardholder operations.
* **`railway_inquiry_system.c`** — Terminal inquiry system for checking train schedules, routes, and reservation details.
* **`bus_inquiry_system.c`** — Intercity bus schedule, route lookup, and fare calculation system.
* **`hotel_management_system.c`** — Console management tool for room availability, guest check-in/check-out, and billing.
* **`online_education_portal.c`** — Interactive course catalog and student registration menu system.
* **`calculator_system.c`** — Command-line calculator supporting standard arithmetic and mathematical operations.

---

## 🛠️ Prerequisites

To compile and run these programs locally, ensure you have a C compiler installed:
* **GCC** (Linux / macOS / Windows via MinGW)
* **Clang** or any standard ANSI C99/C11 compiler

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/prageeshjaiin/c-console-applications.git](https://github.com/prageeshjaiin/c-console-applications.git)
   cd c-console-applications
   ```

2. **Compile any `.c` source file:**
   ```bash
   gcc hdfc_banking_system.c -o hdfc_banking_system
   ```

3. **Run the executable:**
   * **Linux / macOS:**
     ```bash
     ./hdfc_banking_system
     ```
   * **Windows (Command Prompt / PowerShell):**
     ```cmd
     hdfc_banking_system.exe
     ```

---

## 💡 Core Concepts Demonstrated

* **Procedural Architecture:** Decomposing complex workflows into reusable, single-responsibility C functions.
* **Control Flow & Menu Loops:** Managing multi-level user navigation with `switch-case`, `while`, and `do-while` loops.
* **Input Validation & Formatting:** Handling user inputs and rendering clean tabular outputs in the terminal.
